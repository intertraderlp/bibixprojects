Install the VideoVue extension

VideoVue is a small Chrome extension that lets you watch protected videos you were given a link to. No account or sign-in is needed.

From the Chrome Web Store

Not published yet. Until then, install it manually:

Manual install (Chrome, Edge, Brave)

  1. Download and unzip the extension-video folder you received.
  2. Open chrome://extensions and switch on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Go back to the video link and click I installed it.
